# Usage and configuration

[Back to the README](../README.md)

## Choose a mode

Use Right Option when you are talking to an AI about something already in its conversation: "Change that function to handle empty input" or "Run the same check on the other file." The cleanup prompt asks Claude to make the reference specific only when the destination window identifies it. Your receiving AI still decides how to act on the prompt.

Use Right Command for a message or note whose wording you want to keep. This mode asks for transcription corrections and punctuation without expanding references from context. Both modes send the captured window text to Claude.

## Work across conversations

The destination is captured when you stop recording. Place the cursor in the intended input field before the second tap. If you move to another window or input field while processing runs, the result stays on the clipboard for manual pasting.

Recent dictations are held in memory for up to 20 minutes, with at most 20 entries. Only entries matching the destination window and its title are included in a request. Changing the title excludes earlier entries. Conversations that share an unchanged window title may not be distinguishable, so this is not a guarantee of conversation isolation. Restarting the app clears this memory.

Only text exposed through macOS Accessibility is available. Load the relevant messages in the destination window before dictating. A terminal with hidden scrollback or a custom interface may expose little usable context. If the context is missing, the cleanup prompt asks Claude to keep unresolved references as spoken. There is no verified app compatibility matrix yet.

## Configure the app

Edit `~/.config/option-prompt/config.json` and restart the app after changes. Settings you omit use the defaults in [config.py](../config.py). Paths may start with `~`.

| Setting | Built-in default | What it controls |
| --- | --- | --- |
| `language` | `zh` | Whisper language. The example config uses `en`; `auto` enables detection. |
| `fix_model` | `haiku` | Claude model alias for dictation cleanup |
| `prompt_model` | `sonnet` | Claude model alias for AI prompts |
| `fix_timeout` | `20` | Dictation cleanup timeout in seconds |
| `prompt_timeout` | `45` | AI prompt cleanup timeout in seconds |
| `low_probability` | `0.6` | Word-probability threshold for flagging uncertain recognition |
| `context_chars` | `12000` | Maximum characters retained from the window-text snapshot; use a positive integer |
| `background_file` | Empty | Path to a UTF-8 file with optional background notes |
| `glossary_files` | `[]` | List of paths to UTF-8 terminology files |
| `sensevoice_dir` | Empty | Optional SenseVoice model directory |
| `whisper_model` | `~/.local/share/option-prompt/models/ggml-large-v3-turbo-q5_0.bin` | Speech model used when starting the local server |
| `whisper_url` | `http://127.0.0.1:8178/inference` | Speech recognition endpoint |

The word-probability threshold is a recognition hint. It does not measure whether Claude's interpretation is correct. Inline alternatives are generated by Claude and can also be mistaken; the output does not attach confidence percentages to them.

`context_chars` caps the text sent after a bounded Accessibility traversal. It does not guarantee that every message, or the most recent message, was captured. Lower the positive value to send less window text. The current app has no switch to disable context capture; window identity, title, and matching recent dictations can also be included.

### Add project terminology

Create a local text file, for example `~/.config/option-prompt/glossary.txt`:

```text
Savio: a computing cluster
PyTorch: the machine learning library
parser.py: the parser module
```

Add its path to your config, preserving your other settings:

```json
{
  "language": "en",
  "glossary_files": ["~/.config/option-prompt/glossary.txt"]
}
```

A glossary supplies spelling and terminology hints to Claude; it does not retrain Whisper or enforce literal text replacements. Optional `background_file` notes serve the same reference role. Together these files contribute at most 16,000 characters per request. Their contents are sent to Claude, so include only material you intend to share with that provider.

Background notes do not substitute for the destination conversation when resolving "that file" or similar references.

### Add a second recognizer

SenseVoice can supply another transcript for Claude to compare with Whisper:

```sh
.venv/bin/python -m pip install sherpa-onnx
```

Download a compatible model following the [sherpa-onnx SenseVoice guide](https://k2-fsa.github.io/sherpa/onnx/sense-voice/index.html). Set `sensevoice_dir` to the directory containing `model.int8.onnx` and `tokens.txt`, then restart. Check the model's supported languages and license separately. If the optional recognizer cannot run, the app continues with Whisper.

### Use a separate configuration

Set `OPTION_PROMPT_CONFIG_DIR` to a directory containing another `config.json`:

```sh
OPTION_PROMPT_CONFIG_DIR=~/.config/option-prompt-work .venv/bin/python start.py
```

This selects a configuration at startup. The app does not switch profiles automatically; run one instance at a time because the shortcuts are shared.

### Use an existing speech server

Set `whisper_url` to a compatible whisper.cpp `/inference` endpoint. If the configured port is already reachable, `start.py` reuses it without checking which model or service is listening. It starts a server only for an unavailable local endpoint, and stops only the server it started when you quit.

With an existing server, `whisper_model` does not change that server's loaded model. Restart or reconfigure that server yourself when changing models. A remote endpoint receives the audio, so the default local-audio behavior no longer applies.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| A shortcut does nothing | Enable Input Monitoring and Accessibility for the launching terminal or Python process, restart the app, and tap the right-hand modifier alone. Holds longer than half a second do not count. |
| Recording fails or captures nothing | Check Microphone permission and the macOS default input device. Recordings under 0.3 seconds are ignored. |
| Speech is recognized in the wrong language | Check `language` in your config and restart. Use `en`, `zh`, or `auto` as appropriate. |
| The app asks you to install whisper-cpp or download a model | Check `command -v whisper-server` and the configured `whisper_model` path. |
| Transcription fails with a server running | Confirm `whisper_url` points to a whisper.cpp-compatible inference endpoint, rather than another service using the same port. |
| You get the transcript without cleanup | Look for `AI unavailable; using transcript` in the terminal. Check Claude CLI authentication, account limits, model access, and timeouts. |
| "That file" stays unresolved | Bring the relevant conversation text into view and check Accessibility permissions. Some apps do not expose enough text. |
| The result is copied but not pasted | Refocus the intended input field and press Cmd+V. The app uses this fallback when it cannot confirm the original window and field still have focus. |

If you report a problem, include your macOS version, processor type, destination app, shortcut, and a short invented example of the input and result. Remove private text, file paths, and credentials from logs before sharing them.
